# Bloom Drops — Unity Concept

Same remix as the web prototype: **Two Dots** → bioluminescent botanical essences in a twilight meadow.

| Essence | Role |
|---------|------|
| Coral Rose | Warm petal glow |
| Mint Dew | Cool leaf light |
| Sun Pollen | Golden nectar |
| Sky Drop | Rain-kissed blue |
| Night Blossom | Soft dusk pink |

**Bloom Burst**: closing a loop (or 2×2 square) clears every drop of that essence.

Built for Unity 2022.3 2D, portrait mobile (`com.playcard.bloomdrops`).
